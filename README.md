# House Shifting

Frontend and backend files now live in the same root project folder.

```text
house-shifting/
├─ .next/
├─ node_modules/
├─ public/
├─ src/
│  ├─ app/
│  ├─ components/
│  ├─ config/
│  ├─ controllers/
│  ├─ middlewares/
│  ├─ models/
│  └─ routes/
├─ package.json
├─ server.js
└─ README.md
```

## Run Frontend

```bash
npm run dev
```

## Run Backend

```bash
npm run backend:dev
```

## Run Both Together

```bash
npm run dev:all
```
